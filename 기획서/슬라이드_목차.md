## 1. 구성 방식 후보 5개 [제안]

| 번호 | 방식 | 장 수 | 장점 | 단점 |
|---|---|---|---|---|
| 1 | **원고 그대로 (소제목 1개 = 1장) + 페르소나 분리** | 본문 21장 | 원고·근거와 1:1로 맞아 수정·검증이 쉽다. 면접 질문 대부분에 해당 장이 있다 | 장 수가 많아 제출본으로는 길 수 있다 |
| 2 | 압축형 (배경+타깃, 가격+채널 등 묶음) | 13~15장 | 10분 발표에 맞는다 | 표·근거가 작아져 읽기 어렵다. 원고 재작성 필요 |
| 3 | 직무별 2벌 (MD·브랜드 / PM·프로덕트) | 공통 17장 + 직무별 2~3장 | 지원 직무에 맞춰 강조점을 바꿀 수 있다 | 관리할 파일이 둘. 아직 지원사가 미정 |
| 4 | 스토리형 (문제 → 답 → 증명 → 실행) | 12장 + 부록 10장 | 흐름이 강하다 | 원고 순서를 크게 바꿔야 하고, 데이터가 부록으로 밀린다 |
| 5 | 비주얼 우선 (이미지·광고를 앞에, 근거를 뒤에) | 18장 | 첫인상이 강하다 | 상품기획 직무에서는 근거가 뒤로 밀려 의도가 약해 보일 수 있다 |

**추천: 1번.** 원고가 이미 1장 단위로 쓰여 있고 모든 결정에 근거가 붙어 있어, 옮기는 과정에서 내용이 바뀌거나 빠질 위험이 가장 적다. 길이가 문제가 되면 1번 완성본에서 덜어내 2번이나 3번을 만드는 것이 반대 방향보다 쉽다.

- 면접 예상 질의응답(Q1~Q21)은 슬라이드에 넣지 않고 면접 준비용 문서로 둔다 [제안].
- 13장 "지원사 맞춤"은 지원사가 정해지면 1장씩 추가한다. 지금은 빼 둔다 [제안].

## 3. 조립 전에 정할 것 / 고칠 것

> 11-23 사용자 확정: 1 = 1번(원고 그대로 21장) / 2 = 원고 반영 (포트폴리오 v0.5에 반영 완료) / 3 = 추천대로 (라인업·미니는 있는 컷으로 대체, 패키지 평면도만 확정 색으로 새로 그림 → `디자인/패키지시안_v2/` 시안 1 영문 라벨 확정, 2·3 삭제)

1. **구성 방식**: 위 1~5번 중 선택 (추천 1번)
2. **원고와 결과물이 어긋난 곳** — 조립 전에 원고를 고쳐야 한다 [확인]
   - 9-1장 "광고 방향: 채움/잠금 두 칸 화면 분할" → 최종 광고는 v5 재료 플랫레이(단색 배경 + 와인 명조). 문구 수정 필요
   - 9-2장, 12-1장은 아직 "작성 예정" 자리만 있다 → 내용 작성 필요 (색은 11-20 확정, 근거 문서 있음)
   - 0장·5장·6장·8장의 이미지 자리 설명(이미지 A~D)이 실제 선택 컷과 다르다 → 위 표 기준으로 정리
3. **없는 이미지**
   - 6장 "라인업 6종 한 컷": 세럼은 이미지가 없다 → 크림·토너 4종으로 대체할지, 세럼 포함 6종 컷을 새로 만들지
   - 8장 "가을 듀오 + 미니 증정 컷": 미니는 이미지가 없다 → 듀오 컷으로 대체할지
   - 13번 슬라이드 패키지 평면 시안: 기존 `디자인/패키지시안/`은 확정 전 시안이다 [확인] — 색이 웜 그레이·세이지 그린·차콜이고 토너가 300ml. 확정안(와인 투톤 / 감 오렌지 투톤, 토너 150ml 스프레이)으로 다시 그릴지, 이 장은 제품 컷으로 대신할지
