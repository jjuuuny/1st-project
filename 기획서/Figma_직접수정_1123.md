# Figma 직접 수정 가이드 (2026-11-23)

- 배경: Figma 무료 요금제의 MCP 호출 한도에 걸려 총괄 세션이 Figma를 더 고칠 수 없다. 남은 수정은 사용자가 Figma에서 직접 한다.
- 송현준 님 피드백 (11-23): ① 문단 나눔과 글자 정렬만 정리하면 된다 ② 마지막 장은 누끼를 다시 따면 좋겠다.

## 1. 글자 정렬 — 공통 기준 (모든 장에 같은 값)

| 항목 | 값 |
|---|---|
| 왼쪽 여백 | 모든 글·표·이미지의 왼쪽 끝 x = 140 (오른쪽 끝 x = 1780) |
| 위쪽 | 장 번호·장 이름 y = 100 / 구분선 y = 145 / 제목 y = 180 / 한 줄 메시지 y = 278 |
| 본문 시작 | y = 380 (모든 장 같게) |
| 출처 줄 | y = 1010, 왼쪽 정렬. AI 고지는 오른쪽 끝(x 1780)에 오른쪽 정렬 |
| 2단 배치 | 왼쪽 단 x 140, 오른쪽 단은 장마다 정한 한 값으로 통일 (예: 1220) |

**Figma에서 하는 법**
1. 장 프레임 안에서 맞출 글 상자를 여러 개 선택한다.
2. 오른쪽 Design 패널 맨 위의 정렬 버튼에서 "왼쪽 정렬"을 누른다. 또는 X 값에 140을 직접 입력한다.
3. 같은 줄에 있는 것(예: 표의 한 행)은 "위쪽 정렬"로 맞춘다.
4. 반복되는 간격(불릿 사이 등)은 묶어서 선택 → 오른쪽 아래 "간격 균등" 아이콘(Tidy up)을 누른다.

## 2. 문단 나눔 — 공통 기준

- **한 줄은 40자 안팎.** 넘으면 의미 단위(쉼표, "→", 괄호 앞)에서 줄을 바꾼다.
- **줄 바꿈은 Shift + Enter.** 같은 문단 안 줄바꿈이라 간격이 일정하게 유지된다. Enter는 새 문단.
- **단어 중간에서 끊기지 않게.** Figma는 한글을 글자 단위로 끊는다. 단어가 갈리면 그 앞에서 Shift + Enter.
- **소제목(굵게) ↔ 설명** 간격 4, **항목 ↔ 항목** 간격 22로 통일. 글 상자를 묶어 Auto layout(Shift + A)으로 감싸면 간격이 자동으로 지켜진다.
- 글 상자는 "Auto height"(Design 패널 Text → 높이 자동)로 두고 폭만 정한다.

## 4. 마지막 장(21) — 누끼 교체

- 누끼 파일: `디자인/누끼/합성_D6_누끼.png` (크림 + 토너, 배경 투명). 같은 방식으로 `보정_D8_누끼.png`도 만들어 둠.
- 배치 시안: `디자인/누끼/마무리_시안1~3.png` (사용자가 번호 선택)
- **Figma에서 하는 법**
  1. 21장 왼쪽 사진(합성_D6) 사각형을 선택해 지운다.
  2. 21장 프레임 배경색이 #EAE0CF인지 확인한다 (다른 장과 같음).
  3. `합성_D6_누끼.png`를 프레임 안으로 끌어다 놓는다.
  4. 고른 시안의 위치·크기로 맞춘다 (시안 1: 높이 760, x 200, y 170).
  5. 그림자: 이미지 선택 → Effects "+" → Drop shadow, X 18 / Y 22 / Blur 26 / 색 #521827 / 투명도 18%.
  6. 고른 시안에 맞춰 글 위치를 옮긴다.
