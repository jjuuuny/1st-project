## 세션 2에 보낼 명령어

```
git pull로 main 최신을 받은 뒤 CLAUDE.md, 기획서/상품기획서.md(특히 4장·5장), 기획서/경쟁분석.md, 기획서/경쟁분석_토너젤크림.md, 기획서/도구조사.md를 읽어.

너의 추가 역할은 "6~7단계(패키지 디자인, 제품 이미지, 광고 이미지, 상세페이지)를 만들기 전 디자인·이미지 레퍼런스 조사"야. market-researcher 에이전트를 써도 돼.

조사할 것:
1. 패키지 레퍼런스: 경쟁분석.md의 장벽 크림 9개 + 수분 세럼·토너 상위 제품의 용기 형태(튜브/에어리스/자 용기/펌프), 용량 표기 방식, 주 색상, 서체 느낌(세리프/산세리프), 정보 배치. 표로 정리하고, 미니멀 디자인 기준에서 겹치지 않는 빈자리를 [해석]으로 적어. 용기 형태별 장단점(원가, 위생, 사용감)도 함께.
2. 상세페이지 구조: 상위 장벽 크림 3~5개의 상세페이지 섹션 순서(후킹 문구 → 고민 → 성분 → 실증 → 사용법 → 후기 등). 공통 구조와 차이를 정리해. 모바일 기준.
3. 광고 비주얼 트렌드: 올리브영·인스타그램에서 장벽·수분 크림 광고 이미지의 구도(제품 단독/텍스처 클로즈업/모델/물방울 등), 색감, 문구 길이. 표시·광고 위반 소지가 있는 이미지 유형(피부 속 침투 연상 등)도 같이 표시해 (기획서/규제_시험조사.md 1장 참고).
4. 올리브영에서 장벽 크림 상위 5개와 수분 젤크림·토너 상위 제품의 '기획 구성(증정) + 실제 판매가'를 다시 확인해. 토리든 다이브인 수딩크림 단종 여부와 토리든 토너 정가(21,000원 vs 42,000원)도 확인해. 막히면 막혔다고 적어.

규칙:
- 실존 브랜드의 로고·디자인을 베끼기 위한 자료가 아니라, 겹치지 않게 피하기 위한 자료라는 관점으로 정리해.
- 이미지 파일은 저장소에 올리지 말고, 출처 URL과 설명만 적어.
- 확인한 사실, [해석], 출처·신뢰도를 구분해.
- 결과는 기획서/디자인레퍼런스.md 한 파일에만 쓰고 다른 파일은 수정하지 마.
- main 브랜치에 push하고, 끝나면 1st-project-77 세션에 "디자인레퍼런스 완료, push함"이라고 메시지 보내.
```

## 세션 3에 보낼 명령어

```
git pull로 main 최신을 받은 뒤 CLAUDE.md, 기획서/규제_시험조사.md, 기획서/도구조사.md, 기획서/지원후보회사.md, 기획서/네이밍_데이터조사.md를 읽어.

너의 추가 역할은 두 가지야. market-researcher 에이전트를 써도 돼.

[A] 1차 자료 재확인 → 기획서/1차자료_재확인.md
총괄 세션에서는 아래 사이트가 열리지 않아 2차 자료로만 확인했어. 이 세션에서 직접 열어서 원문으로 확인해:
1. 식약처 "화장품 표시·광고 관리 지침" 민원인 안내서(안내서-0086 계열) 원문: '속', '피부 속', '침투', '피부장벽', '보호' 관련 금지·허용 예시
2. 식약처 "피부장벽의 기능을 회복하여 가려움 등의 개선에 도움을 주는 화장품의 인체적용시험 가이드라인" 원문: 피험자 수, 기간, 평가 항목, 시행일
3. 화장품법 제2조(정의), 제13조(부당한 표시·광고 금지) 조문 (law.go.kr)
4. KIPRIS 상표 검색: 온결+ONGYEOL+ONGYEUL+온껼 (유사군 G1201 한 번, 조건 없이 한 번). 결과가 화면에 안 나오면 안 나온다고 적어
5. DART: 달바글로벌, 에이피알 2025 사업보고서의 매출·영업이익·판관비·광고선전비·직원 수·1인 평균 급여
열리지 않는 사이트는 어떤 오류였는지 적어.

[B] 이미지 생성 가이드 → 기획서/이미지생성_가이드.md
사용자는 ChatGPT 무료를 먼저 쓰고, 다음으로 제미나이 무료를 쓸 예정이야.
1. OpenAI 약관·이용 정책 원문: 무료 플랜 생성 이미지의 소유권과 상업적 사용(공개 포트폴리오 포함) 허용 여부, 무료 플랜 생성 한도, 보이는 워터마크 유무와 메타데이터(C2PA) 포함 여부
2. Google 제미나이 약관·도움말 원문: 무료 생성 이미지의 상업적 사용, 보이는 워터마크와 SynthID가 붙는 조건, 유료 플랜(Google AI Pro 등)에서 보이는 워터마크가 빠지는지, 워터마크를 지우거나 가리는 행위에 대한 약관 조항
3. 화장품 용기 목업용 프롬프트 작성법: 용기 형태·재질·조명·배경·구도를 지정하는 방법, 한글 글자가 깨지는 문제와 해결법(글자는 나중에 따로 얹는 방식 등), 같은 제품을 여러 컷에서 일관되게 유지하는 방법. ChatGPT와 제미나이 각각에 맞는 예시 프롬프트 3개씩
4. 실존 브랜드와 혼동되지 않게 하는 체크리스트 (기획서/도구조사.md 3장 보완)

규칙:
- 약관 해석은 원문 문장을 짧게 인용하고 [해석]을 따로 적어.
- 워터마크·SynthID를 몰래 제거하는 도구나 방법은 조사하지 마. 약관상 허용되는 방법(유료 플랜, 공식 설정 등)만 정리해.
- 결과는 위 두 파일에만 쓰고 다른 파일은 수정하지 마.
- main 브랜치에 push하고, 끝나면 1st-project-77 세션에 "1차자료·이미지가이드 완료, push함"이라고 메시지 보내.
```
