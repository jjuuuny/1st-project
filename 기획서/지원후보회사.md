**지원 후보로 먼저 볼 3곳 (의견)**: 토리든(수분 콘셉트 직접 연결), 달바글로벌(레퍼런스, 상장사라 공시 확인 쉬움), 서린컴퍼니(수분 라인 + 상여금 공고 확인). 결정은 사용자가 한다.

## 3. 지원 회사가 정해지면 포트폴리오에서 맞출 것

1. 재무 3개년 (DART): 매출, 영업이익, 판관비율, 광고선전비, 매출원가율
2. 직원 수, 1인 평균 급여 (사업보고서). 상여금 기준은 공고·면접에서 직접 확인
3. 제품군: 기초 카테고리별 비중, 올리브영 상위 SKU, 수분·장벽 라인 여부
4. 채널 비중: 올리브영 / 자사몰 / 해외
5. 최근 전략 변화: 인수·합병, 신규 브랜드, 판관비 급증
6. 경쟁사 견해: 달바 미스트 비중 하락, 아누아 영업이익 감소, 마녀공장 클렌징 편중, 토리든 해외 62%
7. 지원사 1곳 + 경쟁사 1~2곳만 깊게 분석

## 4. 한계와 추가 확인

- 상충 수치: 고운세상 매출, 아모레퍼시픽 매출, 달바 영업이익 1,011억 vs 1,015억
