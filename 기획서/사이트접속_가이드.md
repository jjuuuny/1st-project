# 세션 ②~⑤에서 막힌 사이트 — 원인과 푸는 방법 (2026-11-20 새벽 확인)

## 1. 지금 환경 설정 [확인]
- 세션 ①~⑤는 모두 같은 클라우드 환경 **"1st-project"** 를 쓴다.
- 이 환경의 네트워크는 **unrestricted(제한 없음)** — 모든 공개 사이트가 허용된 상태다. **환경 설정을 더 바꿀 것은 없다.**
- 프록시 상태 점검: 최근 중계 실패 없음.

## 3. 푸는 방법
| 막힌 이유 | 방법 | 누가 |
|---|---|---|
| 하위 에이전트 도구가 못 엶 (DNS 실패) | 세션에 **"하위 에이전트 말고 직접 curl이나 브라우저(Playwright)로 열어"** 라고 지시 | 총괄 세션이 지시할 때 넣음 (다음부터 적용) |
| 자바스크립트 페이지 | 세션에 설치된 Chromium(Playwright)으로 열기 | 같음 |
| 올리브영·쿠팡 등 봇 차단 (403) | **PC 세션(데스크톱 앱 Code + Claude in Chrome)** 으로 사용자 크롬에서 열기 — 11-17·18에 올리브영 확인을 이 방법으로 성공함 | 사용자가 PC 세션에 문장 붙여넣기 |
| 식약처 등 해외 IP 차단 | 같음 (PC 세션, 국내 IP) | 사용자 |
| 유료 리포트 | 무료 요약·보도자료로 대체, 또는 사용자 구독 | - |

- 클라우드 세션이 사용자 PC 폴더를 직접 쓰는 방법(Remote Control)은 11-17 확인 때 "연결 가능한 폴더 0개"였다. 지금은 **PC 세션에 붙여넣는 방식**이 가장 확실하다.
- 권장: 봇 차단 사이트 조사가 생기면 총괄 세션이 **PC 세션용 문장**을 만들어 준다.
