# 건성·지성 라인 분리와 유분 성분 조사 (2026-11-21)

> 계기: 온결은 DRY / OILY 두 라인(토너·크림)으로 나눈다. 건성 토너 = 2층(물층 + 동백 씨오일 5%) 스프레이 확정. **지성 토너를 ① 오일 없는 한 층으로 할지, ② 가벼운 오일 약 3%를 넣은 2층으로 할지** 결정하기 위한 조사.
> 방법: 이 세션에서 브랜드 공식몰·글로벌 공식몰을 **헤드리스 브라우저(Chromium)와 curl로 직접 열어** 전성분과 피부 타입 표기를 옮겼다. 하위 에이전트는 쓰지 않았다.
> 표기: **[확인]** 원문 직접 확인 / **[해석]** / **[미확인]**. 전성분 순서 = 함량 순서(1% 이하 성분은 순서 자유)라는 일반 규칙에 기대어 "앞쪽/뒤쪽"을 판단했다.
> 한계: 국내몰(아모레몰 403 등)이 막혀 **대부분 미국·글로벌 공식몰 전성분**이다. 국내 판매품과 처방이 다를 수 있다. 가격은 미국 달러 정가(2026-11-21 확인)이며 원화와 직접 비교하지 않는다.

## 0. 요약

| 질문 | 답 |
|---|---|
| 건성/지성으로 나눠 파는 브랜드가 흔한가 | **흔하다.** 확인한 9개 브랜드 모두 크림을 '건성용 리치 크림 / 지성·복합용 젤(워터) 크림'으로 나눈다. 토너는 클리니크(1~4단계)처럼 타입별로 나누는 곳이 있지만, 대부분은 토너 하나 + 크림만 나눈다 |
| 지성용 = 오일 없음인가 | **크림은 아니다.** 지성용 젤 크림 9개 중 전성분에 오일·에스터·실리콘이 **하나도 없는 제품은 없었다.** 대신 ① 무거운 오일(미네랄 오일·바셀린·마카다미아) 대신 **가벼운 성분**(실리콘, 휘발성 탄화수소, 가벼운 에스터, 스쿠알란)을 쓰고 ② 개수가 적다. 라네즈 지성용 젤은 **메도폼씨 오일이 4번째**, 이니스프리 지성용 젤은 **카프릴릭/카프릭트라이글리세라이드 4번째** |
| 지성용 토너는 | **확인한 지성용 토너는 모두 무오일**이다 (클리니크 클래리파잉 로션 3, 토리든 밸런스풀 필링 토너, 라운드랩 독도 토너). 단, **건성용 토너도 대부분 무오일**이다 (클리니크 1.0, 라운드랩 자작나무). 토너에 오일을 넣는 것 자체가 소수다 |
| 지성용 2층 제형 | **찾지 못함.** 2층 제품은 모두 '전 피부용' 또는 건성 쪽이었다 (`오일토너_시장조사.md`: 바이오던스는 '가벼운 포도씨 오일 3%'를 민감·트러블 피부에 맞는 이유로 설명) |
| 우리 지성 토너 [해석] | **① 한 층 무오일이 시장 관행과 맞고 위험이 낮다.** ②(2층 + 가벼운 오일 3%)는 라인 통일감은 크지만 "지성용인데 오일층이 보인다"는 설명 부담이 크다. 2층을 유지하려면 오일을 '가벼운 에스터·스쿠알란'으로 바꾸고 1~2%대로 낮추는 절충안이 있다 |

## 3. 해석

### 3-1. '지성용 = 오일 없음'이 업계 일반인가

- **크림: 아니다.** 지성용 젤 크림도 유분 성분을 넣는다. 다만 ① 개수를 줄이고(1~3개) ② 무거운 오일 대신 **실리콘·가벼운 에스터·스쿠알란**을 쓴다. 식물성 오일을 앞쪽에 넣은 지성용 제품도 있다(라네즈 메도폼 4번째).
- **토너: 대체로 그렇다.** 지성용 토너는 확인한 3개 모두 무오일이다. 하지만 건성용 토너도 대부분 무오일이라, "지성이라서 오일을 뺐다"기보다 **토너는 원래 오일을 거의 안 넣는다**고 보는 편이 정확하다.
- 결론: **"지성용 크림에 가벼운 유분은 흔하다, 토너에 오일은 건성·지성 모두 드물다."**

### 3-2. 우리 지성 토너 선택에 주는 시사점

| 기준 | ① 한 층 무오일 | ② 2층 + 가벼운 오일 3% |
|---|---|---|
| 시장 관행 | **맞음.** 지성용 토너는 확인한 사례 모두 무오일 | 지성용 2층 사례 없음. 관행과 다름 |
| 지성 고객 설득 | 쉬움. "오일 0" | 어려움. 병 안에 오일층이 **보여서** 지성 고객이 바로 망설일 수 있음 |
| 라인 통일감 | 약함. DRY만 2층 → OILY는 다른 제품처럼 보임 | 강함. 두 라인 모두 '채움 + 잠금' 2층 구조로 같은 이야기 |
| 콘셉트 ("채우고, 잠그는") | OILY에서는 '잠금'을 크림(젤크림)이 맡는다고 설명해야 함 | 토너에서도 잠금을 보여 줌 |
| 처방·원가 | 단순 | 2층 안정성·분사 막힘 확인이 두 SKU로 늘어남 |
| 면접 질문 | "왜 지성은 2층이 아닌가" → "지성 토너는 오일 없이, 잠금은 젤크림이 맡는다"로 답 가능 | "지성용인데 왜 오일을 넣었나" → 가벼운 오일 선택 근거(바이오던스식 설명)와 함량 실증이 필요 |

**[해석] 추천: ① 한 층 무오일.**
- 근거: 확인한 지성용 토너는 모두 무오일이고, 지성용 2층 사례가 없다. 시장 관행이 분명하고 위험이 낮다.
- 라인 역할 분담 설명이 자연스럽다: **DRY = 토너(2층)와 크림 둘 다에서 잠금**, **OILY = 토너는 채움만, 잠금은 젤크림의 가벼운 유분(실리콘·가벼운 에스터)이 맡음.** 실제 지성용 젤 크림들이 유분을 소량 넣는 관행(2-1)과도 맞는다.
- 가장 강한 반론: 두 라인의 시각적 통일감(2층)이 깨진다. → 대응: 용기 디자인(같은 병 형태, 색만 다름)으로 통일감을 유지하고, OILY 토너는 '한 층 = 가벼움'을 오히려 차별 메시지로 쓴다.
- ②를 고르는 경우의 절충안: 오일을 식물성 오일 대신 **가벼운 에스터나 스쿠알란**으로, 함량은 건성(5%)보다 확실히 낮게(1~2%대). 바이오던스처럼 "가벼운 오일을 고른 이유"를 상세페이지에 적는다. 함량 수치는 처방사 확인 전제(가상 시나리오).
