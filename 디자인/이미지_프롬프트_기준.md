# 이미지 프롬프트 기준 (사용자 확정, 2026-11-17 밤)

> 근거: 사용자가 생성 결과 5묶음을 비교해 정한 기준. 앞으로 모든 제품·광고 이미지 프롬프트는 이 기준을 통과해야 보낸다.

## 좋은 예 (사용자 인정)
- 감 오렌지 2층 CUT 1~6, 와인 단색 2층 CUT 1~6, 브라운 2층 1~6, 와인 투톤 2층 CUT 1~6
- 공통점: **칸마다 구도가 다르고, 배경도 다르고, 배경 톤이 그 제품 색에 맞음.** 구도 테스트에 어울리는 배경을 함께 까는 것은 괜찮다.

## 나쁜 예 (사용자 반려)
- 감 오렌지 밀키 16칸: 같은 구도 반복, 거의 같은 이미지 중복, 토너가 빠진 칸
- 배경 플레이트 4종: 구도가 모두 같음(오른쪽 받침 고정), 배경 2개씩 거의 같음, 무엇을 고르라는지 목적 불명

## 보내기 전 체크리스트
1. 칸마다 **구도가 서로 다른가** (정면 / 위에서 / 기울임 / 접사 / 쌓기 / 반사 등 겹침 없음)
2. 칸마다 **배경이 서로 다른가** (재료·빛·색이 겹치지 않음)
3. 배경 톤이 **그 색 방향에 맞는가** (와인=버건디·아이보리, 브라운=흙·돌·리넨, 감 오렌지=모래·햇빛·크림)
4. **크림 튜브와 토너가 모든 칸에 다 있는가** (접사 컷은 한 제품 중심이어도 다른 제품이 흐리게라도 보이게)
5. 칸 수는 **6칸 이하** (16칸처럼 많으면 중복·누락이 생김)
6. 프롬프트 앞에 **"이걸 보고 무엇을 판단하면 되는지"** 한 줄
7. 'ONGYEOL' 철자가 깨지기 쉬움 → 결과에서 확인 (감 오렌지 CUT 묶음에서 깨짐)

## 도구별 관찰 (사용자 정보, 2026-11-17 밤)
- 감 오렌지 2층 CUT 묶음 = **Gemini**: 구도·배경 다양성은 좋았으나 'ONGYEOL' 철자가 여러 칸에서 깨짐. 오른쪽 아래 보이는 워터마크 있음 (지우지 않음).
- 와인 단색·브라운·와인 투톤 2층 묶음 = **ChatGPT**: 철자 정상, 제품 모양 유지 양호.
- [해석] 글자가 들어가는 제품 컷은 ChatGPT 우선. Gemini 결과를 쓸 때는 글자 확인 필수, 또는 글자 없이 생성 후 Figma에서 얹기.

## agy (Google Antigravity CLI) 이미지 모델 확인 (2026-11-19, agy v1.5.12, Antigravity 세션 확인)
- [확인] 생성 경로: agy 메인 에이전트 → `image-generator` 서브에이전트 → `generate_image` 도구. 실제 인자는 `AspectRatio`(예: "3:2"), 이름, 프롬프트. 결과 JPEG 1264×848(약 1MP).
- [확인] C2PA 메타데이터: 서명 Google LLC, "Created by Google Generative AI", "Applied imperceptible SynthID watermark". → 지우지 않음 (CLAUDE.md 규칙).
- [미확인] **실제 이미지 모델 이름·버전**: 로그·설정·메타데이터 어디에도 없음. agy는 "Nano Banana 계열(Nano Banana 2 = gemini-3.1-flash-image, Pro = gemini-3-pro-image)"이라 답했지만 **웹 공개 자료를 검색해 쓴 답**이라고 스스로 밝힘.
- [미확인] 해상도 지정(agy는 512px~4K 가능하다고 답함, 실제 호출에는 비율 인자만 보임), 무료 한도 수치(`/usage`로 확인 가능하다고 답함, 미실행).
- 포트폴리오 표기 [제안]: "Google Antigravity CLI 이미지 생성 도구(Google 생성형 AI, SynthID·C2PA 포함)로 생성한 가상 브랜드 목업". 모델명은 쓰려면 "Antigravity 공식 문서 기준 Nano Banana 계열"처럼 출처를 밝힌다.
