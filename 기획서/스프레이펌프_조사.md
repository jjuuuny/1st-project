### 2-3. 미세분사(fine mist) vs 연속분사(continuous mist)

| 항목 | 미세분사 펌프 | 연속분사(프리컴프레션, 예: Flairosol류) | 출처·구분 |
|---|---|---|---|
| 작동 | 한 번 누르면 한 번 짧게 분사 | 누르고 있는 동안 3~5초 고르게 분사 | hccpackaging.com 가이드 [검색 요약·원문 일부], USPTO 특허 8905271 (Flairosol: "discrete input pump strokes to a continuous spray") [검색 요약] |
| 1회 분사량 | 화장품용 보통 0.12~0.15ml | 공개 수치 비교 못 함 | custompackingco.com [원문] |
| 입자 | 20~100µm (자료마다 다름) | 50~80µm라는 자료와 더 곱다는 자료가 충돌 | 업체 블로그 [검색 요약] — 수치 신뢰 낮음 |
| 오일·점도 | 저점도 전용. 20~50cPs 세럼·가벼운 오일은 "too viscous" | 공급사가 "Viscosity, oil content, and nozzle clogging risk"를 샘플 전 확인 항목으로 명시 | custompackingco [검색 요약], hccpackaging [원문] |
| 소비자 리뷰 비교 | **두 방식을 직접 비교한 페이셜 미스트 소비자 리뷰는 찾지 못함** | | |

- [해석] 연속분사는 "안개처럼 오래 나오는" 사용감이 장점이지만, 공급사 스스로 노즐·처방에 더 민감하다고 쓴다. 2층 제형은 흔든 직후 섞인 상태로 짧게 써야 하므로 **한 번 누름 = 정량 분사인 미세분사가 맞다.**
