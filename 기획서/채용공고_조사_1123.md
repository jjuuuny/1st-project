# 채용 공고 조사 (2026-11-23)

> 확인 일시: 2026-11-23 17:50~18:40 UTC (2026-11-24 02:50~03:40 KST). 공고는 수시로 마감·수정되므로 지원 전 다시 확인한다.
> 방법: 세션 ④가 사람인 검색·상세 페이지와 회사 채용 페이지를 curl·헤드리스 브라우저로 직접 열람. 지원·로그인·문의는 하지 않았다.
> 표기: [확인] 원문 직접 확인 / [해석] / [미확인]. 매출은 `지원후보회사.md`, `1차자료_재확인.md` 기준(공시 = 높음, 보도 = 중간).

> 지원자 조건 요약: 비화장품(반려동물 라이프스타일) 디자이너 + 생산관리 약 5년, 기획·디자인·공장 관리, 시즌 상품 성수기 월 매출 2억. **화장품 상품기획 실무 경력은 없음** → "화장품 상품기획 N년 이상"을 필수로 거는 공고는 자격 미달 위험이 있다 [해석].

## 0. 요약

- A그룹(매출 300억↑·상여 표기) 회사들의 **상품기획·BM 공고는 대부분 "화장품 상품기획 4~5년 이상"**을 요구한다 (브이티 4년↑, 마녀공장 5년↑, 셀리맥스 4~10년, 애경 LUNA 5~10년, 클리오 BM 7~13년). 지원자 경력과 직접 맞는 것은 적다.
- 경력 조건이 맞는 A그룹 공고는 **디자이너 직무**(라운드랩·토리든·에이피알 패키지 디자이너)와 **인턴**(마녀공장 상품기획 리서치 인턴)이다.
- 직무가 정확히 맞는 A그룹 공고는 **더파운더즈 [ANUA] 글로벌 상품기획 매니저(2~10년)**이지만 "코스메틱 상품기획 실무 2년 이상"이 필수다.
- B그룹(인디 포함)은 1~5년·경력무관 스킨케어 상품기획 공고가 많다. 특히 **NINELESS 스킨케어 BM(상품기획·생산관리, 2~5년)**은 생산관리 경력과 직접 맞는다.

### A그룹 추천 3곳 [해석]

1. **마녀공장 — 상품기획 리서치 인턴 (~11/30)**
   - 이유: A그룹 중 **경력 조건이 확실히 맞는 상품기획 직무는 이것뿐**이다. 업무(성분 논문 서치, 채널별 시장조사, 제품 포트폴리오 자료)가 이 포트폴리오의 조사 문서(성분·경쟁·시장)와 거의 같아 "이미 해 본 일"로 증명할 수 있다.
   - 위험: 인턴(정규직 전환 여부는 공고 텍스트에서 [미확인]), 상여 [미확인], 매출 1,130억(보도). 마감이 가장 빠르다.
2. **더파운더즈 — [ANUA] 글로벌 상품기획 매니저 (채용 시 마감)**
   - 이유: 직무 설명("브랜드 메시지-제형-고객 니즈를 연결하는 히어로 제품 기획, USP 수립, 출시 일정 관리")이 포트폴리오 구조와 가장 정확히 겹친다. 아누아는 '화해 어워드 수분 부문 1위'를 내세우는 스킨케어 브랜드라 수분 장벽 콘셉트와 맞는다. 매출 기준 크게 충족.
   - 위험: **필수 "코스메틱 상품기획 실무 2년 이상"을 충족하지 못한다.** 공고 복리후생에 성과급 표기가 없다(상여 기준은 [미확인]). 비화장품 기획·생산 5년을 '상품기획 실무'로 인정받을지가 관건.
3. **서린컴퍼니(라운드랩) — 패키지 디자이너 (~12/05)**
   - 이유: **성과급과 명절 상여금이 공고에 명시**돼 3개 기준을 모두 충족하고, 디자인 3년↑ 조건도 맞는다. 디자인 + 생산관리 경력이 패키지(용기·단상자·부자재) 업무와 직접 맞는다.
   - 위험: 목표 직무(MD·BM·PM)가 아니다. 근무지가 강원 춘천이다. 라운드랩 동백 라인과 이 포트폴리오의 원료가 겹치므로 면접에서 차이(꽃 = 탄력 / 씨오일 = 잠금, `경쟁분석.md` 6절)를 설명해야 한다.
   - 대안: 토리든 패키지 디자이너(1~6년, 상여 [미확인]).

3. **코코스랩 BM(1~5년, 성과급)** — "포토샵 가능자" 요건이 디자인 경력과 맞음.

## 3. 확인 못 한 것

1. 원티드(403)·잡플래닛(403) 공고 → **PC 세션 확인 필요**. 원티드에는 사람인에 없는 스타트업·브랜드사 공고가 많다.
2. 상세가 이미지로만 된 공고(셀리맥스, SKIN1004, 토리든 패키지 디자이너, 에이피알 등)의 상여·경력 세부 조건.
3. 크레이버코퍼레이션, 애경산업, B그룹 회사들의 매출·사원 수.
4. 코스알엑스·고운세상의 자체 채용 페이지.
5. 잡코리아·리멤버 교차 확인 (이번에는 사람인 위주).
