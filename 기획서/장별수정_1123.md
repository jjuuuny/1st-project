- 제목: **채움 크림 DRY와 2층 토너**
- 한 줄 메시지: **처방 전 방향이다 — 실제 원료·비율은 ODM 처방 역량과 안정도 시험으로 정한다**
- 표 (3열: 항목 / 채움 크림 DRY / 채움 토너 DRY (2층))

| 항목 | 채움 크림 DRY | 채움 토너 DRY (2층) |
|---|---|---|
| 제형 방향 | 수상 비율이 높은 크림 → 바를 때 수분감, 흡수 후 지질 성분이 얇게 남는 2단 텍스처 | 아래 수분층 + 위 오일층(약 5%), 흔들면 섞였다 다시 나뉨 |
| 채움 성분 | 히알루론산, 글리세린, 판테놀 | 글리세린, 히알루론산 (수분층) |
| 잠금 성분 | 세라마이드 조합(세라마이드엔피 등) + 콜레스테롤 + 지방산, 스쿠알란, 동백 씨오일 | 동백 씨오일(Camellia Japonica Seed Oil) 중심 오일층 |
| 동백 씨오일 | 에몰리언트로 세라마이드·스쿠알란과 함께 마무리감 | 오일층의 주인공 — 전성분에서 오일 중 앞에 오도록 |
| 공통 원칙 | 향료 무첨가, 색소 최소화. '저자극' 문구는 첩포시험 근거가 있을 때만 | 같음 + 층 분리·펌프 막힘 안정성 시험 |

- 출처 줄: **근거: 피부 지질 구성(세라마이드·콜레스테롤·지방산) 처방 사례 · 2층 오일 토너 시장 조사 · 처방은 가상 시나리오**
