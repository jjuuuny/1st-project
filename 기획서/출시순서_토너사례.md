## 2. 패턴 [해석]

- **"토너를 먼저 내고 크림을 나중에 내는" 순서는 사례에서 찾지 못했다.** 신규·인디 브랜드의 "토너 진입 → 크림 확장" 사례도 찾지 못했다 (토리든은 세럼, 라운드랩·아누아는 출시 경위 미확인).
- 가장 자주 확인된 패턴은 **"크림(또는 세럼) 히어로와 토너를 같은 날 내고 듀오·세트·증정으로 묶는 것"**이다 (에스트라, 리얼베리어). 다만 2건 모두 대형·중견 브랜드라 신규 브랜드에 그대로 적용하기는 어렵다.
- 따라서 출시 순서 ⑤의 "토너 먼저"는 근거가 없고, **"크림과 토너 동시(듀오)"**로 바꿔야 사례와 맞는다.

## 3. ③ vs ⑤ 비교 [해석]

| 기준 | ③ 건성 3종 가을 → 지성 3종 봄 | ⑤ 히어로 크림 + 토너 2종 가을 → 세럼·젤크림 |
|---|---|---|
| 초기 SKU | 3 | 3 |
| 지성 고객 유입 | 약 6개월 늦음 (2030 고민 검색은 수부지 계열이 더 큼) | 가을부터 토너로 진입 (핵심 지성 제품은 여전히 늦음) |
| 세트 | 가을에 건성 풀세트 가능 | 가을에 크림 + 토너 듀오 가능 (에스트라 방식) |
| 계절성 | 장벽 크림 겨울 수요와 맞음 | 크림은 맞음. 토너 계절성은 확인 못 함 |
| 히어로 집중 | 가장 강함 | 토너가 진입 역할을 맡으면 흐려질 수 있음 |
| 사례 근거 | 찾지 못함 | 크림 + 토너 동시 출시와 가까움 (2건) |

- 재고·SKU는 비슷하다. 차이는 **지성 고객 진입 시점**과 **히어로 집중도**다.
- 토너 역할은 사용자가 M③(라인 구성용 300ml 23,000원 + 소용량 증정)으로 정했다 → 토너는 체험용 저가가 아니라 라인 본품이다.
