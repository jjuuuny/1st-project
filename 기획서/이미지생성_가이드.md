> 조사: 이 세션의 직접 열람(curl·헤드리스 브라우저) + market-researcher 에이전트 2개.

> - **[요약 조회]** 에이전트가 웹 조회 도구로 확인. 요약 모델을 거쳐 글자 단위로 원문과 같다는 보장이 없음

## 0. 요약

| 항목 | ChatGPT 무료 | Gemini 무료 |
|---|---|---|

| 다운로드 해상도 | [미확인] | 무료 1K, AI 플랜 2K [원문] |

**결론 [해석]**
1. **포트폴리오에 "AI로 생성한 가상 브랜드 목업"이라고 밝힌다.** Google 약관은 AI 생성물을 사람이 만든 것처럼 속이는 행위를 금지하고, 숨겨진 SynthID·C2PA는 어차피 남는다. 밝히는 편이 약관과 면접 신뢰도 양쪽에 맞다.
2. Gemini 무료 결과물에는 보이는 워터마크가 남는다. **한국에서 공식적으로 끄는 방법은 AI Ultra 구독뿐이다.** Pro로는 빠지지 않는다. 워터마크가 있는 상태로 쓰거나, 워터마크가 거슬리지 않는 구도(여백 구석)로 만든다.
3. ChatGPT 약관 원문은 국내 브라우저에서 직접 확인해야 한다 (6장 체크 항목).
4. 상업적 사용 허용 문구는 어느 쪽도 원문으로 확인하지 못했다. 면접용 비판매 포트폴리오는 위험이 낮아 보이나, 실제 판매용 상세페이지·광고로 쓰는 것은 별도 확인이 필요하다.

## 3. 화장품 용기 목업 프롬프트 작성법

### 3-1. 프롬프트 구성 요소

| 요소 | 지정 방법 | 예시 표현 |
|---|---|---|
| 용기 형태 | 일반 명칭으로. 특정 브랜드를 떠올리게 하는 형태 묘사는 피함 | wide low cream jar with straight sides, slim squeeze tube, dropper bottle, pump bottle |
| 재질·마감 | 구체적으로 | frosted white PP, matte satin finish, clear glass with frosted coating |
| 색 | 무채색 + 브랜드 색 1개 이하 | off-white, pale stone gray |
| 라벨 | 비우거나 영문 짧은 워드마크만 | plain off-white label area, small 'ONGYEOL' wordmark in thin sans-serif |
| 조명 | 광원 위치·성격 | soft diffused light from a large softbox at upper left, three-point softbox setup, soft natural window light |
| 배경 | 단색 심리스 | seamless off-white studio backdrop |
| 구도·카메라 | 앵글 + 프레이밍 + 렌즈 | front view, eye level, centered / overhead flat lay / macro lens, shallow depth of field |
| 비율 | ChatGPT: 크기 지정(1024x1024, 1536x1024, 1024x1536) / Gemini: 문장에 "Square 1:1 format" 등 명시 | |
| 제약 | 원치 않는 것 | ChatGPT: "no extra text, no props" / Gemini: 원하는 것을 긍정형으로 ("empty background") |

**도구별 서술 방식 [요약 조회]**
- **ChatGPT**: OpenAI 쿡북은 형식을 강제하지 않고, 복잡한 요청은 "scene, subject, details, constraints"처럼 **라벨을 붙인 블록**으로 나누라고 권장. "Name materials, lighting, colors, and medium." 사실적 결과는 "photorealistic" 명시. ([OpenAI 이미지 프롬프트 쿡북](https://developers.openai.com/cookbook/examples/multimodal/image-gen-models-prompting-guide.md))
- **Gemini**: "A simple list of keywords won't cut it; you need to describe the scene narratively." → **한 단락 서술형**. 공식 사진 템플릿: "A photorealistic [type of shot] of a [subject] in a [setting]. [light]. Shot from a [camera angle] with a [lens type]." ([Google Cloud 블로그 2026-03-06](https://cloud.google.com/blog/products/ai-machine-learning/ultimate-prompting-guide-for-nano-banana), [AI Studio 문서](https://aistudio.google.com/docs/image-generation)) "Describe what you want, not what you don't want."

### 3-2. 한글이 깨지는 문제

| 근거 | 내용 | 신뢰도 |
|---|---|---|
| Google Cloud 공식 문서 | 한국어(ko-KR)는 **Gemini 3 Pro Image(Nano Banana Pro)**의 권장 언어 목록에만 있음. 2.5 Flash Image 목록에는 없음 | 높음 [요약 조회] |
| 같은 문서 | "When generating an image containing text, first generate the text and then generate an image with that text." | 높음 [요약 조회] |
| OpenAI 쿡북 | 필요한 문구는 따옴표로 묶고 위치·서체 지정, 드문 단어는 철자를 한 글자씩. 한국어 관련 지침은 없음 | 높음 [요약 조회] |
| 언론 | ChatGPT Image 2.0(2026-04)이 한글을 정확히 그린다는 보도. 근거는 사용자 평가 | 중간~낮음 [2차] |

**해결 방식 [해석 — 권장]**
1. **이미지 안에는 한글을 넣지 않는다.** 라벨은 비우거나 영문 "ONGYEOL"만.
2. 한글 브랜드명·제품명·용량·성분은 **Figma에서 따로 얹는다.** 라벨 영역을 평평하고 정면에 가깝게 만들어야 나중에 얹기 쉽다 ("flat label area facing the camera").
3. 이미지 안 영문도 깨질 수 있다. 결과를 확대해 철자를 확인하고, 틀리면 다시 생성하거나 라벨을 비운 버전으로 바꾼다.
4. 한글을 꼭 시험해 보고 싶으면 "온결" 두 글자만 따옴표로 넣어 두 도구로 1회씩 테스트하고 결과를 기록한다.

### 3-3. 여러 컷에서 같은 제품 유지

| 방법 | 근거 |
|---|---|
| **고정 제품 명세 블록**을 만들어 모든 프롬프트에 그대로 붙임 | 두 도구 모두 "유지할 것을 매번 다시 적으라"고 권장 [요약 조회] |
| **같은 대화에서 이어서 편집** ("change only X, keep shape, label, lighting") | OpenAI: "Pass the previous output as the next edit input, request one change, and repeat the details to preserve." / Google: "Multi-turn conversation is the recommended way to iterate on images." [요약 조회] |
| **첫 번째 좋은 결과를 참조 이미지로 업로드** | Gemini는 참조 이미지 여러 장 지원 (모델별 상한 상이) [요약 조회] |
| 제품에 이름을 붙여 부르기 ("the ONGYEOL cream jar") | Google 가이드 권장 [요약 조회] |
| 시드(seed) 고정 | 두 도구 모두 공식 문서에서 찾지 못함 → 쓰지 않음 |

**공통 제품 명세 블록 (두 도구 공용)**
```
Product spec (keep identical in every image): the ONGYEOL cream jar — a minimal cosmetic cream jar, wide and low, straight sides, flat matte lid, frosted white PP body with a soft satin finish, a plain off-white label area facing the camera, no printed graphics. Brand text only: a small 'ONGYEOL' wordmark in a thin sans-serif, nothing else.
```

### 3-5. Gemini 예시 프롬프트 3개

서술형 한 단락. 첫 줄에 명세 블록을 붙이거나, 첫 결과를 참조 이미지로 올린 뒤 "Using the attached image as the exact product design, keep its shape and label area unchanged"를 앞에 쓴다.

## 4. 실존 브랜드와 혼동 방지 체크리스트 (`도구조사.md` 3장 보완)

### 4-1. 체크리스트

**프롬프트 단계**
- [ ] 실존 브랜드명·제품명·"~ 스타일", "like ~"를 쓰지 않았다 (달바 포함)
- [ ] 특정 브랜드의 대표 용기를 떠올리게 하는 형태 묘사를 쓰지 않았다 (일반 명칭만: jar, tube, dropper, pump)
- [ ] 특정 브랜드의 시그니처 색 조합을 쓰지 않았다
- [ ] 실존 로고 서체 이름을 쓰지 않았다 (thin sans-serif 같은 일반 설명만)
- [ ] 실존 인물, 의사·약사 등 전문가 연출(흰 가운, 진료실)을 넣지 않았다 → 화장품법 제13조 제1항 제4호(2026-11-27 시행)와 별표 5 다목 (`1차자료_재확인.md` 3장)

**결과물 단계**
- [ ] 결과물을 역이미지 검색(Google Lens 등)으로 확인해 특정 실존 제품과 흡사하지 않다 [제안, 공식 근거 없음]
- [ ] 이미지 안에 의도하지 않은 글자·로고·가짜 인증 마크가 없다
- [ ] 라벨에 효능 문구("장벽 회복", "피부과 테스트 완료")를 넣지 않았다 → 표시·광고 지침 별표 1·2
- [ ] 피부 속으로 성분이 들어가는 듯한 침투 연출을 넣지 않았다 → 지침의 "전체적인 광고의 인상" 판단 원칙
- [ ] AI 도구의 보이는 워터마크를 지우거나 잘라내지 않았다 (Gemini는 한국에서 Ultra 설정만 허용)

**표기 단계**
- [ ] 포트폴리오에 "가상 브랜드, AI 생성 목업 (도구명, 생성일)"을 적었다 → Google 금지 사용 정책 "Misrepresenting the provenance…"
- [ ] "dupe", "~ 대체품" 같은 비교 표현을 쓰지 않았다
- [ ] 브랜드명 '온결'의 상표 검색 결과를 함께 보관했다 (아직 미확인, `네이밍_데이터조사.md` 2-4)

## 5. 작업 순서 제안

1. ChatGPT 무료로 C-1을 2~3회 생성 → 가장 나은 1장을 기준 이미지로 정함
2. 같은 대화에서 C-2, C-3을 이어서 생성 (명세 블록 반복)
3. 부족한 컷은 Gemini 무료에 기준 이미지를 올리고 G-1~G-3으로 보완 (보이는 워터마크가 남음을 감안)
4. 결과물을 번호 붙여 최소 3개씩 정리 (CLAUDE.md 디자인 원칙) → 사용자가 번호로 삭제
5. 4장 체크리스트 확인 → Figma에서 한글 라벨 얹기
6. 생성 도구, 날짜, 프롬프트를 이 문서 아래나 별도 기록에 남김
