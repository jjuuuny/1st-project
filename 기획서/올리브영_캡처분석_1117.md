## 2. 우리 결정과 연결되는 점 [해석]

| 번호 | 관찰 | 의미 |
|---|---|---|
| 2-1 | 아토베리어365 크림은 올리브영에서 **80ml 2개 + 앰플 '더블 기획' 41,900원**으로 팔림. 크림 1개 환산 약 20,950원, ml당 약 262원 [계산: 41,900 ÷ 160ml, 앰플 제외] | 우리 히어로 100ml / 32,000원(ml당 320원)은 정가 기준으로는 아토베리어보다 싸지만, **올리브영 기획가 기준으로는 더 비싸다**. 올리브영 입점 시(F: 이듬해 겨울) 기획 구성 설계가 필요 |
| 2-2 | 할인율 10~45%, 대부분 24~30%. 구성은 **더블(2개), 리필, 1+1, 미니 증정** | E 결정(올리브영 증정 기획)과 같은 방향. 가격 설계 시 올리브영 할인 분담을 수익 계산에 넣어야 함 (기획서 4-2-1) |
| 2-3 | **일리윤 멀티베리어 리페어 크림** (장벽보습 리페어, 덱스판테놀 5%, PDRN) — 경쟁분석 9개에 없던 신규 장벽 크림 | 경쟁 목록에 추가 필요. 용량은 캡처에서 잘려 확인 못 함. 정가 24,000원 |
| 2-4 | 페이보릿 토너 썸네일에 "**장벽개선 217%**" 같은 실증 수치를 크게 씀 | 실증 수치를 앞면에 쓰는 것이 우리만의 빈자리는 아니다. 다만 크림 히어로에서 "수분량 + TEWL 두 지표"를 함께 보여주는 구조는 화면에 없음 |
| 2-5 | 8개 중 **모델 사용 4개**(메디필, 이니스프리, 아이오페 + 일부), 색은 **파란 계열 다수** | 세션 2의 "대표 이미지 모델 0개" 관찰과 다르다 (판매처 대표 이미지 vs 올리브영 기획전 썸네일 차이). 파랑 배제 방향은 여전히 유효 |
| 2-6 | 제품명 앞에 [11월 올영픽], [NEW/물광수분] 같은 **대괄호 수식어**가 붙음 | 판매 페이지 상품명 운영 원칙(기획서 5-2: 공식명과 검색용 상품명 분리)과 같은 방향 |
