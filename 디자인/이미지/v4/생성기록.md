# 컷 테스트 v4 생성 기록 (2026-11-19)

- 도구: Antigravity CLI(agy) v1.5.12 → 이미지 생성 도구 `generate_image`. 이미지 모델 이름은 로그·메타데이터에 나오지 않아 [미확인].
- 프롬프트: `디자인/컷테스트_v4.md`(origin/main 7a7c72c)의 색별 첫 코드 블록 4개. agy 대화 기록으로 4장 모두 원문과 글자 하나까지 같게 전달된 것을 확인함.
- 비율: 4장 모두 `AspectRatio: 2:3`으로 호출됨. 결과는 848×1264 px.
- 방식: 색마다 agy를 따로 실행함(새 대화 4개, 앞 이미지 스타일 이어받지 않음).
- 파일: `v4_색.png`는 보기용 PNG(무손실 변환). `v4_색_원본.jpg`는 생성 원본 그대로(C2PA 메타데이터 포함). PNG 변환 때 C2PA 메타데이터는 빠지므로 원본 JPEG를 같이 둠. 픽셀에 들어간 SynthID 워터마크는 손대지 않음.
- 판독 한계: 칸 하나가 약 420px라 용량 표기는 글자 높이가 몇 픽셀임. 3배 확대로 읽은 값도 [추정].

## 색별 상세

### 와인 투톤 (`v4_와인투톤.png`)
- 6칸: 모두 있음. 칸 번호 1~6 정상.
- 두 제품: 모든 칸에 있음. 5번은 프롬프트대로 뒤에서 흐리고 잘림. 튜브 투톤(아이보리 위 / 와인 아래) 정상.
- ONGYEOL: 전 칸 정상.
- 용량 [추정]: 3번 토너 "150 ml" 정상. 2번 튜브는 "100"인지 "300"인지 판독이 애매함. 4번 토너는 "190/160 ml"처럼 보여 오류 의심.
- 토너: 슬림 반투명 병 + 와인 오버캡, 상단 오일층(옅은 노랑) 보임. 오버캡이 긴 원통형이라 스프레이 펌프가 보이지 않음. 오버캡을 씌운 상태라 프롬프트와는 모순되지 않지만, 사진만으로 스프레이인지 알 수 없음.
- 하단 링: 2·3·4·5번에서 얇게 나옴. 1번은 잘 보이지 않음.

### 와인 단색 (`v4_와인단색.png`)
- 6칸: 모두 있음.
- 두 제품: 모든 칸에 있음. 6번은 프롬프트대로 토너 클로즈업 + 튜브 흐림.
- ONGYEOL: 2번 토너 글자 깨짐("SNGYLE…"처럼 보임). 나머지 정상.
- 용량 [추정]: 3번 토너 "100 ml"(150이어야 함), 4번 토너 "140 ml"처럼 보임, 2번 튜브 판독 불가. 오류 많음.
- 토너: 층 경계 창이 라벨 띠처럼 나오고 그 위에 ONGYEOL이 찍힘(3·5·6번). 4번은 병 안에 스포이트 같은 관이 보임. 펌프는 오버캡에 가려 안 보임.
- 하단 링: 3·4번은 얇게 나옴. 1·2·5번은 거의 안 보임.

### 브라운 (`v4_브라운.png`)

- 두 제품: 모든 칸에 있음.
- ONGYEOL: 전 칸 정상.
- 용량 [추정]: 1번 튜브 "100 ml" 정상, 1번 토너 "500 ml"처럼 보임, 4번 토너 "100 ml", 4번 튜브 "300"처럼 보임, 5번 튜브 "300"처럼 보임. 오류 많음.

## 공통 관찰
- 용량 표기는 글씨가 너무 작게 나와 오류가 잦음. 실제 시안에서는 Figma에서 다시 얹는 편이 안전함 [제안].
