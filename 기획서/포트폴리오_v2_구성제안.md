# 온결 포트폴리오 v2 — 구성 변경·시장조사 추가 [제안] (2026-11-29)

> 배경: 송현준 님 피드백(완성도 5~8% 수준) → 라인업 중심 구성, 이미지·페이지 보강. 사용자가 먼저 문단·특수문자를 수정하고 레퍼런스를 모은 뒤 확정한다. 목표 30~40장.
> 제작 방식: 지금처럼 SVG → Figma 끌어다 놓기 (Figma MCP 횟수 불필요). 이미지는 사용자 서칭 후 필요분만 ⑤(agy).

## 1. 구성 후보 5개

| # | 구성 | 흐름 | 장점 | 단점 |
|---|---|---|---|---|
| 1 | **브랜드 → 라인업 → 비즈니스 → 크리에이티브** | 시장·타깃·콘셉트 → 라인업 맵 → 제품별 상세(6종) → 가격·채널·수량 → 패키지·광고·상세 | 제품이 가운데에 와서 "무엇을 만들었나"가 바로 보임. 지금 내용 재활용률 높음 | 장 수가 가장 많이 늘어남(제품별 1~2장) |
| 2 | 라인업 먼저 (제품 → 근거) | 라인업 맵·제품 컷으로 시작 → 왜 이렇게 만들었나(시장·타깃) → 숫자 | 첫인상이 강함 | 근거가 뒤로 가서 상품기획 논리가 약해 보일 수 있음 |
| 3 | 히어로 집중 + 라인업 요약 | 히어로 크림을 5~6장으로 깊게, 나머지 5종은 1장씩 | 실무 기획서에 가까움(히어로 1개 집중 전략과 일치) | 라인업 구성 요청과 거리 |
| 4 | 출시 순서(타임라인) 구성 | 가을 듀오 → 첫 겨울 → 봄 4종 → 올리브영 순으로 제품을 등장 | 출시 전략이 이야기로 읽힘 | 제품 비교가 흩어짐 |
| 5 | DRY / OILY 두 권 구성 | 공통 브랜드 → 건성 라인 전체 → 지성 라인 전체 | 패밀리룩이 잘 보임 | 지성 라인 이미지·자료가 부족 |

**추천: 1번.** 피드백의 "라인업 구성"을 가장 직접 반영하면서 지금 23장 내용 대부분을 그대로 옮길 수 있다. 장 수는 약 32~36장 예상.

### 1번 기준 장 구성 초안
- 브랜드(6): 표지, 지원자, 시장 배경, 타깃·페르소나, 경쟁·빈자리, 콘셉트
- **라인업(12~14)**: 라인업 맵 1 · 루틴(토너→세럼→크림) 1 · **제품 6종 × 각 1~2장**(제품 컷, 콘셉트 한 줄, 핵심 성분, 제형·사용감, 용기 사양, 용량·가격) · 처방 가이드 1 · 패밀리룩 1
- 비즈니스(6~7): 가격, 수량·손익, 채널·출시, 런칭 마케팅, 실행 계획, 리스크, 성과 지표
- 크리에이티브(4~5): 브랜딩·패키지 평면도, 광고, 상세페이지, 키비주얼 점검
- 마무리(2): 레퍼런스(달바), 마무리

## 4. 진행 순서
1. 사용자: 지금 23장 문단·특수문자 수정 → **수정본 PDF 또는 수정 문구를 전달** (Figma 직접 읽기는 횟수 제한으로 불가 → PDF로 주면 총괄이 읽고 SVG 원본에 반영)
2. 사용자: 레퍼런스를 `레퍼런스/` 폴더 4개에 정리 (구성 / 제품 이미지 / 라인업·패키지 / 시장조사 자료)
3. 총괄: 구성 후보 확정 → 장별 목차 → 시장조사 추가분 ④ 배분 → 이미지 부족분 ⑤ 배분 → SVG 제작
4. 수정판 완성 후 지원서류(파일명·첨부 장 번호) 다시 정리
