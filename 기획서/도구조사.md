# 도구 조사: Figma 연동 비용, 이미지 생성 도구 (2026-11-16 조사)

> 조사: market-researcher 에이전트. **공식 1차 자료를 열지 못했다** (figma.com, openai.com, policies.google.com, docs.midjourney.com, higgsfield.ai 등 DNS 실패). 아래는 검색 요약·언론·블로그 기준이다.
> 표기: [확인] 2차 자료에서 확인 / [해석] 추론 / 신뢰도 높음·중간·낮음

## 1. Figma 연동 (Claude가 Figma에 직접 그리는 기능)

| 항목 | 내용 | 신뢰도 |
|---|---|---|
| 쓰기(write to canvas) 요금 | **베타 기간 무료.** 정식 전환 후 사용량 기반 유료 예정, 요율·시점 미공개. 베타 시작 2026-03 | 중간 |
| 2026-11 기준 유료 전환 공지 | 확인 못 함 | - |
| 무료(Starter) 계정에서 Drafts에 쓰기 가능 여부 | 확인 못 함 → **본인 계정으로 직접 시험해 보는 것이 가장 확실** | - |
| 좌석별 | Full: Drafts 밖 팀 파일 쓰기 가능 / Dev: Drafts만 | 중간 |
| 읽기 호출 제한 (Starter) | 월 6회 또는 월 20회 (출처 충돌) | 낮음 |
| Starter 파일 제한 | Drafts 무제한, 팀 폴더 Figma 디자인 파일 3개 (블로그) | 낮음~중간 |
| 이미지 생성 기능 | 이 세션의 Figma 연결 목록에 이미지 생성 도구 이름이 보이지만, 비용·조건은 확인 못 함 | - |

[해석] 지금은 무료로 쓸 수 있을 가능성이 높지만, 무료 계정에서 실제로 되는지와 유료 전환 시점은 불확실하다. 작업은 Drafts에서 하고, 필요하면 완성본만 팀 폴더로 옮긴다.

## 2. 이미지 생성 도구: 무료 사용과 상업적 사용(포트폴리오 공개 포함)

| 도구 | 무료 사용 | 상업적 사용 | 신뢰도 |
|---|---|---|---|
| Gemini 앱 | 가능 (일일 한도, 한도는 출처마다 다름). 무료 결과물에 Gemini 로고 워터마크 + SynthID | **판단 불가** (허용·불허 주장 충돌) | 낮음 |
| ChatGPT 무료 | 가능 (횟수 제한) | 출력 소유권은 사용자에게 있다는 약관 인용. 무료 플랜 상업 사용은 주장 충돌 | 낮음 |
| Higgsfield 무료 | 크레딧 거의 없음 | **불가** (회사 블로그 인용) | 낮음 |
| Midjourney | 무료 체험은 비상업(CC BY-NC) | **유료 구독 중 생성분은 가능.** 연 매출 100만 달러 초과 기업은 Pro 이상 | 중간 |
| Seedream(이미지)·Seedance(영상) | 제3자 플랫폼 체험 크레딧 | 공식 약관 미확인 | 낮음 |

[해석] 공개 포트폴리오는 상업적 사용으로 볼 여지가 있다. 무료 등급 결과물은 약관 원문을 확인하기 전까지 쓰지 않는 편이 안전하다. 가장 확실한 길은 상업 사용 조항이 명확한 유료 플랜(예: Midjourney 구독 중 생성)이지만 비용이 든다.

## 3. 용기 목업 시 실존 브랜드 혼동 방지 [해석 + 2차 자료]

- 부정경쟁방지법 제2조 제1호 가목: 타인 상품 표지(용기·포장 포함)와 유사해 출처 혼동을 일으키면 부정경쟁행위 (요약 사이트, 원문 미확인).
- 체크리스트:
  1. 가상 브랜드명과 자체 로고만 쓴다. 실존 브랜드명·로고·서체·용기 실루엣·색 조합을 쓰지 않는다 (달바는 참고만).
  2. AI 생성 용기 이미지는 역이미지 검색으로 실존 제품과 흡사한지 확인한다.
  3. AI 도구 워터마크가 남아 있으면 쓰지 않거나 약관 범위에서 처리한다.
  4. 실존 인물 얼굴을 쓰지 않는다.
  5. 포트폴리오에 "가상 브랜드 목업"이라고 명시한다.
  6. "dupe" 같은 비교 표현을 쓰지 않는다.
