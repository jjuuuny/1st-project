# 배경 무드 레퍼런스 분석 — 동생 예시 (2026-11-17)

> 이미지: 사용자가 대화로 공유 (저장소에는 올리지 않음). 아래는 이미지를 보고 판단한 것 [해석].
> 오른쪽 아래 별 모양 아이콘은 Gemini 생성 이미지의 보이는 워터마크와 같은 모양이다 → Gemini로 만들었거나 Gemini를 거친 이미지로 보인다. 포트폴리오에 쓰면 "AI로 생성한 가상 브랜드 목업" 표기, 워터마크 유지.

## 구성 요소

| 구분 | 요소 | 이 이미지에서 |
|---|---|---|
| 색 | 단색 톤온톤 | 짙은 청록(딥 틸 그린) 벽 + 같은 계열 바닥. 색 하나로 통일 |
| 받침 | 제품 놓을 자리 | 오른쪽 1/3 지점의 거친 자연석 판(슬레이트 느낌). **비어 있음 = 나중에 제품 합성용** |
| 전경 | 앞쪽 식물 | 왼쪽 앞에 잘게 갈라진 잎의 허브류(쑥·당근잎 계열로 보임, 종 확인 불가) + 물방울 |
| 배경 | 뒤쪽 식물 | 같은 식물을 흐리게(아웃포커스) 겹겹이 → 깊이감 |
| 조명 | 로우키 | 전체 어둡게, 위·옆에서 부드러운 빛 하나. 받침 윗면과 잎만 밝음 |
| 카메라 | 얕은 심도 | 전경·배경 흐림, 받침만 선명. 낮은 눈높이 |
| 구도 | 3분할 + 여백 | 왼쪽 전경이 프레임을 감싸고, 위쪽은 문구용 빈 공간 |
| 비율 | 16:9 가로 | 상세페이지 상단 배너·포트폴리오 슬라이드에 바로 맞음 |
| 질감 | 촉촉함 | 잎의 물방울로 '수분' 연상 |

## 우리 프로젝트에 쓸 때 [의견]

- 좋은 점: **빈 받침 + 16:9 + 위쪽 여백** 구조는 광고 이미지·상세페이지 상단(7단계)에 그대로 쓸 수 있다. 제품 사진은 따로 만들어 Figma에서 얹는 방식과 맞는다.
- 맞지 않는 점: 청록 + 허브 + 물방울은 **진정(시카·쑥) 카테고리** 분위기에 가깝다. 우리 콘셉트는 건성 장벽(채움·잠금)이라 그대로 쓰면 메시지가 흐려질 수 있다.
- 바꿀 것: 허브 → **윤기 있는 동백잎 + 동백 씨**, 물방울은 유지(채움), 받침 위 오일 한 방울(잠금) 추가.
- 색 궁합: 청록은 와인·감 오렌지와 보색이라 제품이 또렷하게 보인다. 브라운과는 대비가 약하다.

## 직접 촬영으로 만들 경우 준비물 (참고)
배경지(청록 롤지 또는 페인트 보드), 같은 색 바닥 천, 자연석 판, 생화 잎, 분무기(물방울), 소프트박스 조명 1개 + 반사판, 조리개를 넓게 열 수 있는 렌즈.
