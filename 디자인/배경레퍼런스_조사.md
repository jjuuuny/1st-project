# 배경·세트 디자인 레퍼런스 조사 (2026-11-17)

- 계기: 배경 플레이트·배경 무드 프롬프트 결과 사용자 반려 ("다 별로, 최악"). 반려 기록에 적힌 이유는 **"구도가 모두 같고(오른쪽 받침 고정) 배경도 비슷함"** (`배경플레이트_프롬프트.md` 등 머리말).
- 목적: 실제 브랜드 제품 사진의 배경 **구조**(세트 재료, 받침, 소품, 조명, 색 구성, 구도, 여백, 카메라 높이)를 배우고, 경쟁 브랜드와 **겹치는 배경을 피한다.** 베끼기 위한 자료가 아니다. 로고·용기·특정 세트를 그대로 가져오지 않는다.
- 이미지 파일은 저장소에 올리지 않았다. URL과 설명만 적는다.
- 조사 방법
  - 메인 세션: 공식몰·공식 사이트 첫 화면을 브라우저로 열어 이미지를 **직접 봄** (화면 확인만, 파일 미저장) → [관찰]
  - market-researcher 에이전트 2개 (국내 / 해외 + AI 클리셰): 이미지를 볼 수 없어 기사 본문·alt 텍스트·검색 요약 기준 → [기사] [alt] [검색]
- 표시: [관찰] 메인 세션이 이미지를 직접 봄 / [기사] 기사·케이스 본문 / [alt] 공식 사이트 이미지 대체 텍스트 / [검색] 검색 요약만 / [해석] 추론·의견
- 신뢰도: 높음(공식 사이트를 직접 봄) / 중간(디자인 매체·언론 본문) / 낮음(검색 요약·벤더 블로그)

## 0. 한계

1. [관찰] 사례는 **공식 사이트 첫 화면 배너·대표 이미지 1장씩**이다. 시점은 2026-11-17이고 다수가 홀리데이 시즌 연출이라 바뀔 수 있다. 조명 방향·카메라 높이는 사진을 보고 판단한 것이다 [해석].
2. 공식 페이지 URL은 확인했지만 **이미지 파일의 직접 URL은 적지 않았다** (배너 이미지 주소는 시즌마다 바뀌고 저장소에 올리지 않기로 했으므로). 같은 화면을 보려면 해당 페이지를 열면 된다. 시즌이 바뀌면 사라질 수 있다.
3. 올리브영 상세페이지 대표 이미지는 이 환경에서 403이라 보지 못했다. `기획서/올리브영_용기색_확인.md`(사용자 Chrome 확인)의 용기 색만 참고했다.
4. 따뜻하고 어두운 배경(와인·브라운 계열) 사례는 직접 본 것이 적다 (Diptyque, Le Labo, Augustinus Bader 정도). 4장의 색별 추천은 패턴 구조를 옮겨 쓰는 [해석]이다.
