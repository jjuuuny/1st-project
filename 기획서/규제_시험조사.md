## 1. '속' 표현 ("속까지", "속건조", "속수분")

| 내용 | 신뢰도 |
|---|---|
| '속' 표현을 직접 허용·금지한 식약처 문서는 **찾지 못함** | - |
| 2025-01-21 지침 개정: 사용 방법에 대한 사실 오인 표현 금지 (예: 마이크로니들이 "피부 속으로 성분을 밀어 넣는" 식 표현) | 중간 |
| "피부 깊숙한 층까지 침투" 표현을 과대광고로 판단한 사례 보도 | 중간~낮음 |
| 2026년 적발 유형에 "피부 속 침투를 연상시키는 이미지" 포함 (화장품은 표면 적용) | 중간~낮음 |
| 식약처 표현 체계: ① 금지 표현 ② 효능 입증 조건부 표현 ③ 허용 표현 | 중간 |
| "피부(세포) 재생", "염증 완화" 등 의약품 수준 효능은 금지 | 중간~낮음 |
| "화장품이 작용하는 범위는 각질층"이라는 식약처 문구는 **찾지 못함** (상품기획서 4-1의 해당 문장은 해석으로만 둔다) | - |

[해석] '속'이라는 단어 자체보다 **침투·진피 연상과 근거 없는 효능**이 문제가 될 가능성이 크다. 콘셉트 문장은 각질층 수분량 측정 결과와 함께 쓰고, "피부 속 깊이", "진피까지" 같은 표현과 침투 이미지는 쓰지 않는다.

## 2. "피부장벽" 표현

| 내용 | 신뢰도 |
|---|---|
| 일반 화장품의 "피부장벽", "장벽 강화·개선·회복", "피부 보호", "지키다" 허용 여부: 식약처 유권해석 **찾지 못함** | - |
| 기능성이 아닌데 기능성으로 오인할 표시·광고 금지 (화장품법 제13조 취지) | 중간 |
| "피부장벽의 기능을 회복하여 가려움 등의 개선에 도움을 주는 화장품"은 2020-08 시행규칙 개정으로 기능성화장품 유형에 신설 | 중간 |
| 해당 인체적용시험 가이드라인(민원인 안내서) 등록 2024-12-09. 본문(피험자 수·기간·평가 항목) 미확인 | 중간 |
| 피부장벽 회복 기능성 누적 심사 52건 (2024년 기준, 전체 기능성 19,074건 중) | 중간 |

[해석] "장벽 회복"류 효능 동사는 기능성 심사 대상 문구와 겹쳐 오인 위험이 있다. 상품기획서의 "효능 동사 금지" 원칙과 같은 방향이다. "지키고"가 괜찮은지는 원문 근거가 없다.

## 3. 각질층 수분량·TEWL 인체적용시험

| 내용 | 신뢰도 |
|---|---|
| Corneometer = 각질층 수분, TEWL = 장벽 상태 측정 | 중간 |
| 학술 사례: 4주 사용, 사용 전·2주·4주 측정, 피험자 22~43명 | 중간~낮음 |
| 특허 문서 설명: 처치당 최소 30명 (규제 요건 아님) | 낮음 |
| 시험 전체 일정 100~130일 (출처 URL 특정 못함) | 낮음 |
| **비용(원화)은 찾지 못함.** 항목을 추가하면 비용이 늘고, 여러 효능을 묶으면 절감 가능 | 중간 (금액 없음) |

[해석] 상품기획서 5-4 역산 일정의 "T-6개월 시험 시작"은 4주 사용 + 전체 일정 100~130일과 대략 맞지만, 일정 수치는 출처가 약해 가정으로 둔다.

## 4. MOQ와 개발 기간

| 내용 | 신뢰도 |
|---|---|
| 코스맥스가 인디 브랜드 MOQ를 1만 개에서 1,000개 단위로 낮췄다는 보도 (2023~). '최소 수량'인지 '단위'인지 불명확 | 중간 |
| 소량 제조 업체 광고: 신규 개발 MOQ 1,000개, 기존 처방 500개 | 낮음 |
| 해외 블로그: ODM 기존 처방 200~1,000개, 맞춤 3,000~10,000개. 리드타임 3~16주 또는 4~6개월 (자료마다 다름, 한국 기준 아님) | 낮음 |
| 국내 개인 블로그: 2,000개 제조 약 700만 원 (개당 약 3,500원) | 낮음 |
| 한국콜마가 새 처방 시스템으로 신제품 출시 기간을 약 절반으로 단축 (절대 기간 없음, 2025-02 보도) | 중간 |
| **국내 기초 화장품 개발~출시 개월 수, 안정성 시험 기간은 찾지 못함** | - |

[해석] 해외 수치는 서로 맞지 않아 기획서에 쓰지 않는다. 역산 일정과 MOQ는 "가정, 출처 없음"으로 유지한다. 개당 3,500원 사례는 히어로 크림 원가 가정 6,400원(소비자가 20%)과 비교할 참고값 정도로만 쓴다 (신뢰도 낮음).

## 5. 비교 광고

| 내용 | 신뢰도 |
|---|---|
| 경쟁 제품 비교 광고는 비교 대상·기준을 분명히 밝히고 객관적으로 확인 가능한 사항만 표시. "최고", "최상" 같은 배타적 절대 표현 금지 (식약처 고시 별표 5 취지) | 중간 |
| 표시광고법 부당 광고 4유형: 거짓·과장, 기만, 부당 비교, 비방 | 중간~낮음 |
| 비교 우위의 입증 책임은 광고하는 사업자에게 있음 | 낮음~중간 |
| 화장품 가격 비교 광고 전용 규정은 찾지 못함 | - |

[해석] 상품기획서 4-2에서 "같은 돈에 25% 더" 메시지를 광고에 쓰지 않기로 한 판단과 맞다.
